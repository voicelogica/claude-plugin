# Voice Logica plugin for Claude

Manage Voice Logica AI phone agents from Claude: agents and their prompts, calls with transcripts and summaries, outbound campaigns, workflows, phone numbers and SIP trunks, integrations, SMS and support tickets.

The plugin connects to the hosted Voice Logica MCP server at https://api.voicelogica.ai/api/v1/mcp. You sign in with your Voice Logica account (OAuth) the first time a tool runs. Every tool acts only on your own company's account.

## Install in Claude Code

```
claude plugin marketplace add voicelogica/claude-plugin
claude plugin install voice-logica@voicelogica
```

## What it includes

- The Voice Logica MCP server (remote, OAuth)
- 17 skills for building and fixing agents, phones, calls and campaigns, workflows, CRM, e-shop and ERP lookups, calendars, SMS, integrations and support tickets

You need a Voice Logica account (free sign-up at https://app.voicelogica.ai). Phone calls need a plan with AI minutes.
